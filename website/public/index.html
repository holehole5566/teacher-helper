02 / 課表

  2. 2

GOOD TO KNOW

開始前，
你可能想知道。

需要網路或註冊帳號嗎？

不需要註冊雲端帳號。日常的名單、課表與排程在本機運作；下載程式、同步政府假日、檢查更新，以及啟用 Discord 錯誤通知時需要網路。

班級資料放在哪裡？怎麼備份？

資料存放在本機的 data/config.json。程式優先使用執行檔旁的 data/ 資料夾，若不存在才尋找工作目錄。關閉程式後，備份實際使用的整個 data/ 資料夾即可；更新程式時請保留它。音樂檔需另外保存。

支援哪些電腦？

目前提供 Windows x64 與 Linux x64 下載。Windows 需要 WebView2 Runtime；Linux 需要 GTK 3 與 WebKitGTK 4.1 執行環境，建議使用 Ubuntu 24.04 或相容系統。尚未提供 macOS 安裝檔。

這個網站會讀取班上的學生資料嗎？

不會。這只是功能介紹與下載頁，沒有連接桌面程式或上傳班級資料的功能，也沒有加入追蹤分析程式。若在教室外展示畫面，請留意學生姓名與未交作業的隱私。
